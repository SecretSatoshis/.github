# Code of Conduct

## Our Standard

Secret Satoshis is dedicated to providing a respectful, constructive, and verification-first environment for everyone participating in our open-source repositories, issues, discussions, and pull requests.

## Expected Behavior

- Focus critiques on code, data, methodology, and verifiable evidence rather than individuals.
- Communicate clearly, respectfully, and constructively across differing viewpoints.
- Respect project maintainers' time by providing reproducible bug reports and well-scoped pull requests.

## Unacceptable Behavior

- Harassment, personal attacks, trolling, or derogatory comments.
- Publishing others' private information without explicit consent.
- Spam, promotional shills, or deliberate submission of falsified data or malicious code.

## Enforcement

Maintainers may edit, close, or remove comments, issues, or pull requests that violate this Code of Conduct, and may restrict participation from repeat offenders. To report a concern privately, contact the maintainers through GitHub's repository security/moderation channels.
